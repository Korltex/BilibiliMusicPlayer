# 操作入口

本文集中记录操作前提和权威步骤入口。具体命令和手工检查由 [testing.md](../testing.md) 维护；此处不重复建立命令清单。

## 使用与安装

- 前提：浏览器已安装 Tampermonkey，并开启允许运行用户脚本的设置。用户侧基本说明见 [README.md](../../README.md) 的“注意事项”。
- 本地用户脚本的安装步骤、正式安装来源和部署/托管地址：待核实。构建出文件不等于已安装或已发布。

## 项目验证

- 单元测试、模拟浏览器测试、真实网站烟雾测试及发布前手工检查：按 [testing.md](../testing.md) 的对应章节执行。
- Playwright 浏览器测试依赖先构建；真实网站烟雾测试依赖外部网站和网络状态，具体前置条件以测试说明为准。
- 命令定义见根目录 [package.json](../../package.json)。命令存在只说明已配置，不表示当前或历史某次运行成功。
