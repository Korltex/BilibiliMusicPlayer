# 已证实风险与验证缺口

> 核对日期：2026-10-18；范围：`docs/testing.md` 中的真实网站限制与发布前手工检查说明。

本文只记录本次定位到的现有资料明确支持的问题和验证边界，不代表完整项目风险审计。需要针对新的功能或变更确认风险时，按任务路由查阅相关源码和测试。

## B 站原生播放器行为未被自动化测试完全模拟

- **证据：** [testing.md](../testing.md) 的“发布前手工检查”说明，自动化测试不能完全模拟 Bilibili 内部播放器，并列出真实网站检查项。
- **影响：** 仅有模拟浏览器测试结果不足以证明所有真实播放器交互已核验；这是根据测试范围作出的验证边界判断。
- **保护措施：** 涉及发布时，按测试说明检查真实网站中的播放控制、站内跳转、分 P、连续切歌、后台播放和纯音频回退等相关项目，并单独报告结果。

## 真实网站烟雾测试受外部网站和网络状态影响

- **证据：** [testing.md](../testing.md) 的“真实网站烟雾测试”说明该测试访问公开 Bilibili 页面，依赖外部网络且不属于默认测试命令。
- **影响：** 未运行该测试或网站不可用时，不能声称当前真实网站行为已通过验证。
- **建议措施：** 仅在测试执行成功时报告该次结果；对实时验证不可用的情况明确记录原因，不以历史结果替代。
