# 测试说明

## 单元测试

Vitest 当前覆盖：

- 时间格式化和范围限制
- 顺序播放边界
- 列表循环
- 单曲循环
- 随机播放不重复当前歌曲
- 默认歌单和非法持久化数据恢复

运行：

```powershell
npm test
```

## 浏览器测试

Playwright 使用本地模拟 Bilibili 页面和媒体元素，加载正式构建的用户脚本，验证：

- Shadow DOM 和悬浮按钮挂载
- 页面标题和 UP 主读取
- 添加带起止时间的视频片段
- 歌单持久化
- 点击歌曲后调用媒体播放
- 播放状态同步
- 桌面和 390px 移动视口不越界

运行：

```powershell
npm run build
npm run test:e2e
```

测试优先使用系统 Chrome，其次使用系统 Edge，也可以通过 `CHROME_PATH` 指定浏览器。

## 真实网站烟雾测试

该测试访问一个公开 Bilibili 视频并注入正式构建，检查媒体元素定位和悬浮面板挂载。它使用独立无登录浏览器环境，不读取个人浏览器数据：

```powershell
npm run test:e2e:real
```

因为它依赖外部网站和网络状态，不包含在默认测试命令中。

## 发布前手工检查

自动化测试不能完全模拟 Bilibili 内部播放器。发布前还需要在真实网站检查：

1. 普通视频播放、暂停、进度和音量。
2. 站内推荐跳转后的重新绑定。
3. 分P切换。
4. 浏览器前进和后退。
5. 不同 BV 之间连续切歌。
6. 后台标签页播放至少三十分钟。
7. 两个 Bilibili 标签页之间的播放权切换。
8. 浏览器阻止自动播放时的恢复提示。
